# Taller 4: Aprendizaje No Supervisado

## Descripción
Proyecto de análisis de datos y aprendizaje no supervisado utilizando información de comportamiento de usuarios de Steam, con el objetivo de identificar segmentos de jugadores mediante técnicas de clustering.

## Objetivo
Agrupar usuarios según sus patrones de juego y comportamiento, con el fin de identificar perfiles de jugadores y proponer estrategias de marketing y fidelización.

## Desarrollo del proyecto
- **Exploración de datos:** análisis de dimensiones, tipos de variables, valores nulos, duplicados, estadísticas descriptivas y visualizaciones.
- **Preparación de datos:** limpieza y transformación de variables para el proceso de clustering.
- **Modelado:** implementación de técnicas de aprendizaje no supervisado para identificar grupos de usuarios.
- **Interpretación de clusters:** caracterización de los segmentos según sus patrones de comportamiento.
- **Recomendaciones de negocio:** propuestas de marketing, promociones y fidelización para los segmentos identificados.

## Dataset
[Steam Video Games – Kaggle](https://www.kaggle.com/datasets/tamber/steam-video-games)
